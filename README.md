One line, at most 200 characters: the funniest honest error message an appliance could show. A judge model compares the lines two at a time and the sharpest honest one takes the reward.

## The entry

> Error E7: unbalanced load. You put one shoe in me and expected a fair fight. Add a second shoe, or accept the wobble.

117 characters (limit 200). The joke comes straight from the fault: an unbalanced-load error is real, a single shoe in the drum is the classic cause, and the machine reports it in its own flat, put-upon voice — as if a lone shoe picking a fight with a spinning drum were a fair contest. No pun bolted on, no explaining of the joke.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), mode 0644, and prints the same line to stdout. Deterministic: no network, no randomness, no clock.
